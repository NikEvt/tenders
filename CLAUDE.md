# Ориентиры по репозиторию

Анализ закупок 44-ФЗ: выгрузка из ЕИС, разбор документации, отбор по критериям,
рыночная аналитика.

## Как устроено

Семь сервисов, связанных **только** событиями RabbitMQ и HTTP. Прямые импорты
между ними запрещены и проверяются `lint-imports`.

```
crawler ──tender.ingested──▶ docs-worker ──document.extracted──▶ embedding-service
   ▲                              │
   │ crawl.requested              └─ текст → MinIO, чанки → Postgres
   │
research ──research.requested──▶ (сам себе потребитель) ──HTTP /judge──▶ llm-service
   └─ находки, уверенность, вердикты

api — шлюз: каталог, поиск, фильтры, мониторинг, уровень нагрузки
```

Внутри сервиса слои идут строго `presentation → infrastructure → application →
domain`. `domain` и `application` не знают ни про SQLAlchemy, ни про HTTP.

## Инварианты, которые легко сломать не заметив

1. **`pypdfium2` не потокобезопасен.** Два параллельных разбора PDF в одном
   процессе убивают его нативным сигналом — без traceback. Извлечение обязано
   идти через `ProcessPoolExtraction`; вернуть его в потоки нельзя.
2. **`document_chunks.text` не переносится из Postgres.** На нём генерируемый
   `search_tsv` и весь полнотекстовый поиск. Полный текст документа, наоборот,
   живёт в MinIO — см. `libs/shared/text_objects.py`.
3. **Отбор — запросом, а не пометкой.** Вложение, отклонённое настройками
   (бюджет, приоритет, размер), получает статус `deferred` и ждёт более щедрого
   прогона. Терминальный `skipped` — только для свойств самого файла
   (том архива, подпись). Иначе обзорный проход делает полный невозможным.
4. **Правило отбора закупок живёт в одном месте** — `libs/shared/db/tender_criteria.py`.
   Вторая реализация однажды уже завелась и разошлась с первой: судья получал
   ноутбуки (`26.20.11.110`) в кандидаты фильтра с префиксом `20.11`.
5. **Вспомогательное не роняет основное.** Сборка отчёта, метрики, уведомления —
   в обёртке, ловящей всё. Однажды отчёт унёс с собой полчаса разбора.
6. **Знаменатель обязателен.** «Находок нет» имеет смысл только рядом с
   «прочитано столько-то». Воронка считает и то, до чего не дошли.

## Команды

```bash
.venv/bin/python -m pytest tests/ -q        # 604 теста; integration требуют Postgres
.venv/bin/python -m ruff check .
.venv/bin/lint-imports                       # 4 контракта архитектуры
.venv/bin/alembic upgrade head

docker compose up -d                         # весь стек
curl -X PATCH localhost:8000/system/load-level -d '{"level":1}' \
     -H 'Content-Type: application/json'     # 1 фоновый · 2 средний · 3 полный
```

## Уровни нагрузки

Уровень лежит в `app_settings`, воркеры **опрашивают** его и применяют без
перезапуска: размер пула, prefetch очередей, конкурентность модели, потолок
запросов к ЕИС. Размер пула считается как `min(ядра, память // пик_на_процесс)`;
пик измерен и равен ~182 МиБ (`libs/shared/load_policy.py`).
