================================================================================
  ЗАКУПКИ — УСТАНОВКА НА WINDOWS
================================================================================

Система выгружает извещения из ЕИС, разбирает документацию закупок, отбирает
подходящие по вашим критериям и собирает сводки. Работает целиком на вашей
машине: наружу уходят только запросы к ЕИС и к выбранной вами языковой модели.

Файл открывается Блокнотом — это обычный текст, ничего устанавливать для него
не нужно.


--------------------------------------------------------------------------------
  ЧТО ПОТРЕБУЕТСЯ
--------------------------------------------------------------------------------

  Windows ............ 10 версии 2004 или новее, либо Windows 11
  Docker Desktop ..... последняя версия, с включённым WSL 2
  Память ............. 16 ГБ комфортно, 8 ГБ — минимум (см. раздел о 8 ГБ)
  Диск ............... 25 ГБ свободного места на диске C:
  Токен ЕИС .......... из личного кабинета zakupki.gov.ru
  Ключ модели ........ ваш ключ Yandex Cloud либо своя модель на этой машине

Docker Desktop скачивается с сайта docker.com и ставится как обычная программа.
При первом запуске он предложит установить компонент WSL 2 — согласитесь и
перезагрузите компьютер.


--------------------------------------------------------------------------------
  УСТАНОВКА
--------------------------------------------------------------------------------

  1. Распакуйте архив поставки целиком — например, в C:\zakupki
     Не запускайте файлы прямо из окна архиватора.

  2. Запустите Docker Desktop и дождитесь, пока значок кита станет зелёным.

  3. Двойной щелчок по install.bat — загрузка образов, 5-15 минут.

  4. Двойной щелчок по start.bat. При первом запуске он создаст файл настроек
     и откроет его в Блокноте.

  5. Впишите два значения, сохраните файл и закройте Блокнот:

         EIS_TOKEN=<токен из личного кабинета ЕИС>
         LLM_API_KEY=<ваш ключ доступа к модели>

  6. Запустите start.bat ещё раз. Через несколько минут откроется браузер
     на странице http://localhost:3000

Первый запуск дольше остальных: создаётся база, накатываются миграции,
поднимается брокер очередей. Дальше система стартует за минуту.


--------------------------------------------------------------------------------
  ГДЕ ВЗЯТЬ ТОКЕН ЕИС
--------------------------------------------------------------------------------

Личный кабинет на zakupki.gov.ru → Администрирование → Пользователи →
ваш пользователь → Настройки интеграции → сгенерировать токен.

Токен принадлежит вам и хранится только в файле .env на этой машине.


--------------------------------------------------------------------------------
  ЯЗЫКОВАЯ МОДЕЛЬ
--------------------------------------------------------------------------------

Модель нужна для трёх вещей: собрать фильтр из описания на обычном языке,
разобрать спорные случаи при отборе и написать сводку. Есть два пути.

ОБЛАЧНАЯ МОДЕЛЬ (проще). В .env уже прописан Yandex Cloud, остаётся подставить
свой folder-id в LLM_MODEL и ключ в LLM_API_KEY:

    LLM_BASE_URL=https://ai.api.cloud.yandex.net/v1
    LLM_MODEL=gpt://<ваш-folder-id>/qwen3.6-35b-a3b/latest
    LLM_API_KEY=<ключ сервисного аккаунта>
    LLM_AUTH_SCHEME=Api-Key

СВОЯ МОДЕЛЬ НА ЭТОЙ ЖЕ МАШИНЕ. Если у вас развёрнут vLLM, llama.cpp или Ollama,
укажите его адрес. Из контейнера ваш компьютер виден как host.docker.internal,
а не localhost:

    LLM_BASE_URL=http://host.docker.internal:8080/v1
    LLM_MODEL=qwen3.6-35B-A3B
    LLM_API_KEY=dummy
    LLM_AUTH_SCHEME=Bearer


--------------------------------------------------------------------------------
  ЕЖЕДНЕВНАЯ РАБОТА
--------------------------------------------------------------------------------

  start.bat .... запускает систему и открывает интерфейс
  stop.bat ..... останавливает; данные остаются на месте
  logs.bat ..... показывает журналы; logs.bat crawler — только краулера
  reset.bat .... стирает все накопленные данные, начать с нуля

Запускать нужно именно файлы .bat. Лежащие рядом файлы .ps1 — служебные, они
вызываются из .bat сами; открывать их вручную не требуется.

Систему можно не выключать: она сама обходит ЕИС раз в час. После перезагрузки
компьютера сервисы поднимутся вместе с Docker Desktop.

Нагрузка регулируется на ходу, из интерфейса, без перезапуска:

    1 — фоновый: система почти не мешает работать за компьютером
    2 — средний, по умолчанию
    3 — полный: занимает машину целиком, зато разбирает быстрее

Ставьте 1, если во время разбора компьютер начинает тормозить.


--------------------------------------------------------------------------------
  ЧТО В ЭТОЙ ВЕРСИИ НЕ РАБОТАЕТ
--------------------------------------------------------------------------------

Поиска по тексту документов пока нет в полном виде. Он ищет по словам, а не по
смыслу: запрос «поставка компьютерной техники» найдёт документы с этими словами,
но не найдёт «закупка ноутбуков». Смысловой поиск требует отдельной языковой
модели на 2 ГБ — она в эту поставку не включена и появится позже.

Всё остальное работает полностью: выгрузка из ЕИС, разбор документации (включая
сканы и старые форматы .doc и .xls), отбор по критериям, исследования и сводки.


--------------------------------------------------------------------------------
  ВАШИ ДАННЫЕ И СЕКРЕТЫ
--------------------------------------------------------------------------------

  · Токен ЕИС и ключ модели лежат в файле .env в папке установки. В поставке их
    нет — вы вписываете свои. Не пересылайте .env и не кладите его в общие папки.

  · Пароли базы, брокера и хранилища сгенерированы случайно на вашей машине при
    первой установке. Одинаковых паролей у разных установок не бывает.

  · Служебные порты (база, брокер, хранилище) слушают только сам компьютер:
    из офисной сети к ним не подключиться.

  · Выгруженные закупки, тексты документов и результаты отбора никуда не
    передаются — они лежат в хранилище Docker на этой машине.


--------------------------------------------------------------------------------
  ЕСЛИ ПАМЯТИ 8 ГБ
--------------------------------------------------------------------------------

WSL 2 по умолчанию отдаёт Docker половину памяти компьютера, и стеку этого может
не хватить. Создайте файл C:\Users\<ваше-имя>\.wslconfig такого содержания:

    [wsl2]
    memory=6GB
    processors=4

После этого выполните в PowerShell команду wsl --shutdown и запустите Docker
Desktop заново. И поставьте уровень нагрузки 1 в интерфейсе.


--------------------------------------------------------------------------------
  ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
--------------------------------------------------------------------------------

«Docker не отвечает»
    Docker Desktop не запущен или ещё стартует. Дождитесь зелёного значка кита
    в трее и повторите.

Не хватило места при установке
    Образам нужно около 8 ГБ, плюс место под данные. Освободите диск C: или
    перенесите хранилище Docker: Settings → Resources → Advanced →
    Disk image location.

Интерфейс открылся, но закупок нет
    Первый обход ЕИС занимает время, особенно если в EIS_REGIONS указано
    несколько регионов. Посмотрите logs.bat crawler — там видно, сколько
    извещений уже выгружено.

В журнале краулера ошибка про токен
    Токен ЕИС неверный или истёк. Перевыпустите его в личном кабинете и впишите
    в .env, затем stop.bat и start.bat.

Отбор не даёт результатов, в журнале ошибки llm-service
    Проверьте LLM_API_KEY и LLM_MODEL в .env. У Yandex Cloud в LLM_MODEL должен
    стоять ваш folder-id — при неверном сервис в ответе прямо называет верный.

Если ничего не помогло, пришлите вывод logs.bat — по нему видно, на каком шаге
всё встало.


--------------------------------------------------------------------------------
  ОБНОВЛЕНИЕ ДО НОВОЙ ВЕРСИИ
--------------------------------------------------------------------------------

Распакуйте новую поставку в ту же папку, скопируйте туда свой старый .env и
запустите install.bat, затем start.bat. Накопленные данные сохранятся: миграции
накатятся поверх, база и документы останутся на месте.
