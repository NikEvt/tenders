# Веб-интерфейс

Рабочее место аналитика по закупкам 44-ФЗ. Заменяет временный дашборд на
Streamlit; работает поверх того же `api` на порту 8000.

## Запуск

Вместе со всем стеком:

```bash
docker compose up -d --build web
```

Интерфейс — http://localhost:3000

Отдельно, для разработки (API должен быть запущен):

```bash
cd web
pnpm install
cp .env.example .env.local
pnpm dev
```

Node 20+, пакетный менеджер — `pnpm` (включается через `corepack enable`).

## Переменные окружения

| Переменная | Где живёт | Смысл |
|---|---|---|
| `NEXT_PUBLIC_API_URL` | `web/.env.local` | адрес API для локальной разработки |
| `WEB_API_URL` | корневой `.env` | то же для сборки образа в compose |

Обе задают **адрес, по которому API виден из браузера**. `http://api:8000`
работает только внутри сети compose — из браузера он не резолвится, и это самая
частая причина пустого экрана при первом запуске.

Значение попадает в клиентский бандл на этапе сборки, а не запуска: чтобы
переключить интерфейс на другой хост, образ нужно пересобрать.

```bash
WEB_API_URL=https://zakupki.internal docker compose build web
```

## Команды

```bash
pnpm dev              # разработка, http://localhost:3000
pnpm build            # продовая сборка
pnpm start            # запуск собранного
pnpm lint             # eslint, включая проверку слоёв
pnpm lint:boundaries  # только слои — аналог lint-imports на бэкенде
pnpm typecheck        # tsc --noEmit, strict
pnpm test             # vitest
pnpm gen:api          # типы из OpenAPI, см. ниже
```

## Типы API

DTO руками не пишутся. Схема генерируется из работающего сервиса:

```bash
API_SCHEMA_URL=http://localhost:8000/openapi.json pnpm gen:api
```

Результат — `src/shared/api/schema.d.ts`, он под git и обновляется вместе с
контрактом. Если API не поднят, схему можно снять прямо с приложения:

```bash
cd .. && .venv/bin/python -c "
import json
from services.api.presentation.app import app
print(json.dumps(app.openapi(), ensure_ascii=False))" > /tmp/openapi.json
cd web && pnpm exec openapi-typescript /tmp/openapi.json -o src/shared/api/schema.d.ts
```

Часть ответов FastAPI объявляет как `dict`, и в схеме они выглядят как
`{[key: string]: unknown}`. Их формы описаны руками в `src/shared/api/types.ts`
со ссылками на исходники, из которых они сняты.

### Чего в API не хватает

**`docs/API-GAPS.md`** — список эндпоинтов, которых интерфейсу не хватает, с
готовыми контрактами. Экраны, которые их ждут, показывают честное «эндпоинт не
реализован» вместо правдоподобных чисел. В коде такие места помечены константой
`API_GAP` (`src/shared/api/gaps.ts`) — поиск по ней даёт полный перечень.

Это осознанное решение: интерфейс, который обещает показывать источник каждого
машинного утверждения, не может сам рисовать выдуманные метрики.

## Структура

Слои повторяют дисциплину бэкенда, зависимости идут строго в одну сторону:

```
app → widgets → features → entities → shared
```

```
src/
  app/        маршруты Next: page/layout/loading/error
  widgets/    составные блоки страниц (каталог, сводка, конструктор фильтра)
  features/   действия с последствиями (оценка, компиляция фильтра, экспорт)
  entities/   доменные модели и их атомы (закупка, вердикт)
  shared/     дизайн-система, форматтеры, клиент API, строки
```

Правило проверяется `eslint-plugin-boundaries`; `pnpm lint:boundaries` — прямой
аналог `lint-imports` в Python-части. Импорты вверх и вбок между слайсами
одного слоя запрещены: если двум виджетам нужно одно и то же, это переезжает
в `shared`.

## Шрифты

Golos Text и JetBrains Mono лежат в `public/fonts` как woff2-подмножества
(кириллица + латиница + `₽` и `№`, 88 КБ на все шесть начертаний). CDN не
используется: деплой может стоять в закрытом контуре — та же причина, по которой
в образ вендорится корневой сертификат.

Пересборка после смены версии шрифта:

```bash
bash scripts/build-fonts.sh
```

Скрипт сам ставит `fonttools` во временное окружение. Собственный сабсеттинг
нужен из-за знака рубля: в готовых подмножествах Google он лежит в `latin-ext`,
и без него `₽` на каждом экране рисуется подставным системным шрифтом.

## Дизайн

**`docs/DESIGN.md`** — токены, правило «заметки на полях» для машинного текста
и спецификация шкалы сроков во всех трёх масштабах.

Витрина всех примитивов во всех состояниях: http://localhost:3000/dev/kitchen-sink
Переключите тему в шапке — контраст проверяется там.

## Тесты

```bash
pnpm test
```

Покрыто то, что ломается молча: форматирование денег и дат, русские
числительные, вычисление статуса по датам (правило синхронно с
`Tender.status_at` на бэкенде), геометрия шкалы сроков, определение
деградированного режима модели, очистка OCR-текста, экспорт CSV.

## Известные отклонения от брифа

- **Бандл `/tenders` — 215 КБ вместо заявленных 200 КБ.** Инспектор, командная
  строка и лист горячих клавиш уже вынесены в отдельные чанки; остаток — это
  Query, nuqs, виртуализатор и примитивы Radix, то есть стек из брифа.
  Дальнейшее сокращение упирается в выбор стека, а не в код.
- **Сортировка каталога считается на клиенте** по загруженным строкам: API не
  принимает параметр порядка. Интерфейс это пишет прямо под контролом
  сортировки, а не делает вид, что отсортирована вся выдача.
- **Часть экранов пустые по существу** — см. «Чего в API не хватает».
